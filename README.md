# 四足機器人：自然轉向避障版

雙擊 **`開始自然轉向避障.bat`** 即可啟動。機器狗會讓頭部與身體朝向行進方向，靠四腳踏步轉彎並繞過障礙。
不需要先訓練模型。

此版本保存在新增的「轉向避障版」資料夾，原始專題、「行走修正版」與「避障行走版」均保留。

## 頭部如何一起轉

目前使用的 PyBullet Laikago 模型只有 12 顆腿部馬達，沒有可獨立轉動的頸部關節，頭部固定於機身。
本次修改讓機身實際轉向，頭部因此一起朝向行進方向。

轉彎時會看到：

- 身體逐漸朝向下一段路線，頭部隨機身旋轉。
- 內側腳縮小前後步幅，外側腳加大步幅，前後腳加入轉彎所需的側向落腳量。
- 方向改變較大時先降低前進速度，再轉向前進。
- 轉彎後繼續往頭部朝向的方向步行。
- 抵達終點後停止踏步，保持到達時的朝向。

方向參考經過平滑與轉速限制，減少網格路徑更新造成的左右晃動。
步態轉向指令上限為 0.6 rad/s；實際姿態由腳與地面的物理接觸產生。
沒有透過直接設定身體位置、旋轉角度或施加外力來製造轉彎。

## 操作

啟動後點選模擬視窗，讓鍵盤操作生效。

| 按鍵 | 功能 |
| --- | --- |
| 空白鍵 | 暫停／繼續 |
| `R` | 重跑相同配置 |
| `N` | 更換障礙配置並重新開始 |
| `O` | 在目前頭部朝向的前方約 1.8 m 新增障礙箱 |
| `L` | 顯示／隱藏雷射掃描線 |
| `Esc` 或關閉視窗 | 離開 |

畫面顯示目前航向 `heading`，以及沿頭部前方量測的 `front` 距離。
青色線是目前規劃路徑。雷射為紅色時代表命中障礙，綠色表示量測範圍內沒有命中。
狀態 `GOAL_REACHED` 代表抵達終點；`STOP_BLOCKED` 代表作業範圍內沒有可用路線，機器狗停下等待。

若出現缺少 `numpy`、`gymnasium` 或 `pybullet`，先雙擊 `安裝套件.bat`。
它會在本資料夾建立 `.venv` 並安裝套件，需要網路。啟動器優先使用此環境，否則使用系統 Python。

## 修改重點

| 項目 | 新行為 |
| --- | --- |
| 路徑方向 | 路徑的世界座標速度轉換成目標航向與身體前進速度 |
| 身體朝向 | 依路徑轉動，停止時維持最後朝向 |
| 關節步態 | 每隻腳依前進與轉彎角速度產生不同軌跡 |
| 速度回授 | 在身體座標計算前進速度與側向漂移，保持向前走 |
| 大角度轉彎 | 降低前進速度，讓身體先朝向路線 |
| 前方測距 | 使用機器狗當下朝向判斷前方 |
| 臨時新增障礙 | `O` 的放置方向跟隨目前頭部朝向 |

避障仍使用三高度 360° 雷射掃描、障礙膨脹網格與 A*，依實際量測重新規劃。
雷射最遠 2.8 m，每秒掃描 10 次、規劃 5 次；障礙與機器狗的物理碰撞持續啟用。

## 實測結果

日期：2026-11-09。Windows、Python 3.11.0、PyBullet 3.2.7、NumPy 2.3.5、Gymnasium 1.2.2。

| 測試 | 結果 |
| --- | --- |
| 左轉 45°、右轉 45° | 實際轉身並沿該方向行走；最終朝向誤差小於 5°，與實際移動方向相差小於 8° |
| 行走中改向 90° | 轉身後沿新方向前進，沒有跌倒 |
| 轉彎後的前方測距與新增障礙 | 按目前身體／頭部朝向放置與量測，測試通過 |
| 預設三障礙，seed 42 | 通過 **3/3** 個障礙，抵達終點；**0 碰撞、0 跌倒** |
| 上述身體朝向與實際移動方向的差 | 平均 **2.30°**，95 百分位 **6.38°** |
| 上述實際航向範圍 | 約 **-47.76°～+62.24°** |
| 上述最小障礙間距 | **0.6122 m** |
| 另一組三障礙，seed 1 | 通過 **3/3** 個障礙；**0 碰撞、0 跌倒**；平均方向差 **2.09°** |
| 不同配置、途中新增障礙、整面牆停止、碰撞對照 | 原有避障測試全部通過 |
| 自動回歸測試 | **10 項全部通過**：4 項轉向與 6 項避障 |
| Windows 圖形視窗 | 實際啟動 8 秒，轉向與雷射顯示正常 |

方向差以一個完整步態週期的實際位移計算，使用區間中點的機身航向，降低腳步造成的瞬時速度振動影響。
碰撞間距包含機器狗所有連桿與腳部，不只比較機身中心。
到達終點後再驗證停止 3 秒，沒有用重置掩蓋碰撞或跌倒。

可查看：

- `自然轉向預覽.gif`：實際模擬動畫，約三倍速播放。
- `轉向軌跡.png`：實際路徑；箭頭代表身體與頭部朝向。
- `轉向驗證結果.json`：兩組場景的完整軌跡、方向與碰撞數據。
- `轉向測試紀錄.txt`：10 項測試的執行紀錄。

## 重新測試

雙擊 `驗證轉向與避障.bat` 可重新執行 10 項測試，需約數分鐘，依電腦效能而定。

在本資料夾開啟 PowerShell：

```powershell
# 自然轉向與避障展示
.\run_python.bat obstacle_demo.py

# 更換配置、顯示雷射
.\run_python.bat obstacle_demo.py --seed 7 --show-rays

# 單一障礙或整面牆
.\run_python.bat obstacle_demo.py --layout single
.\run_python.bat obstacle_demo.py --layout blocked

# 無視窗評估與 JSON 紀錄
.\run_python.bat obstacle_demo.py --headless --report my_turning_result.json

# 完整轉向與避障測試
.\run_python.bat -m unittest -v test_heading test_obstacles
```

無視窗模式預設上限 120 秒。到達終點並站穩 3 秒後結束；無路可通且持續等待 8 秒，回報 `stopped_blocked`。
時間到但未抵達會回報 `time_limit`。碰撞與跌倒會停止並回報失敗。

## 程式與範圍

主要修改位於 `obstacle_env.py`；`obstacle_demo.py` 新增航向顯示、軌跡與方向差統計；`test_heading.py` 驗證實際轉身與朝向。
`navigation.py` 的地圖與 A* 沿用前版。基本平地行走的 `go2_env.py` 原樣保留。
原有 `開始自動避障.bat` 在本資料夾也會啟動新轉向控制；建議使用名稱較明確的 `開始自然轉向避障.bat`。

`開始行走.bat`、`eval.py`、`go2_train.py` 保留原有平地展示與 PPO 殘差訓練用途。
本次轉向避障使用步態控制與路徑規劃，不需要 PPO 模型。

這是 PyBullet 平地模擬，尚未接實機。支援固定箱體與行走途中新增障礙，不包含快速移動物體、樓梯或坑洞。
地圖保留已看到的障礙表面；移除或移動箱體後，請按 `R`／`N` 重建地圖。
作業範圍為 X：`-1.5～11 m`，Y：`-3～3 m`；範圍內無可用路線就停下。

## 模型來源

模型由安裝的 `pybullet_data` 提供，見 [PyBullet 官方 Laikago 模型](https://github.com/bulletphysics/bullet3/tree/master/examples/pybullet/gym/pybullet_data/laikago)。
Laikago URDF 由 Erwin Coumans 建立，網格源自經 Unitree 授權的 CAD 模型。
PyBullet 引用：Erwin Coumans and Yunfei Bai, *PyBullet, a Python module for physics simulation for games, robotics and machine learning*, 2016–2018, https://pybullet.org。
